# MTS Marketolog SMS Templates Optimus

Десктопное приложение для анализа SMS-шаблонов, отправленных через агрегатор
МТС-Маркетолог: активность шаблонов, фактическая стоимость, экономическая
выгода и поиск кандидатов на шаблонирование.

## Требования

- Python 3.12+
- [uv](https://docs.astral.sh/uv/)

## Быстрый старт

```bash
uv sync --extra ui
uv run mts-templates
```

Проверки:

```bash
uv run pytest -q
uv run ruff check .
uv run mypy src
```

Без UI-зависимостей (`uv sync`) работают тесты, линтер и импорт через слой
приложения; десктопное приложение требует `--extra ui` (PySide6).

## Что уже работает

- Десктопный интерфейс (PySide6): импорт, дашборд, шаблоны, кандидаты, экспорт,
  настройки. Долгие операции — в `QThreadPool` с индикатором занятости и кнопкой
  «Отмена» в статус-баре, таблицы — `QAbstractTableModel` с сортировкой и
  фильтром.
- Выбор темы оформления в «Настройки → Внешний вид»: 13 авторских тем
  (необрутализм, биофильный дизайн, кассетный футуризм, швейцарский
  минимализм, тёмный ар-деко, эфирный градиент, лоу-фай уют, ризограф-панк,
  ваби-саби, Y2K-хром, редакционный модерн, советский космос,
  мемфис-постмодерн) плюс системная, с миниатюрами интерфейса. Тема
  применяется сразу при клике, сохраняется в `settings.toml` и сбрасывается
  к системной; карточки подсвечиваются при наведении и отмечают выбор
  галочкой. Все палитры проходят WCAG AA, а цвет текста в таблицах
  подбирается по контрасту с фоном строки. Архитектура и инструкция по
  добавлению темы — `docs/themes.md`.
- Архитектура по DDD: ограниченные контексты, единый язык, агрегаты с
  инвариантами, доменные сервисы, anti-corruption-адаптеры. Правила и глоссарий —
  в `AGENTS.md`, разделы 5.1–5.6.
- Тарифные модели: пакетная (`uniform`/`marginal`), подписочная (блоки на
  получателя и месяц), оплата по факту; каталог тарифов с датами действия.
- Расчёт экономической выгоды шаблона и кандидата. Baseline шаблона — средняя
  стоимость сегмента обычных SMS периода × сегменты срабатываний; экономия
  кандидата — фактическая стоимость группы минус оценка по средней стоимости
  сегмента шаблонированных SMS, стоимость шаблона (2 000 ₽/мес) вычитается из
  месячной экономии. В таблице кандидатов выгоду показывает колонка
  «Выгода/мес».
- Цвет строки по выгоде — и у шаблонов, и у кандидатов: пять зелёных уровней с
  настраиваемыми порогами (по умолчанию 1 / 3 000 / 10 000 / 30 000 / 100 000 ₽),
  убыток — слабо-красный, ноль — без цвета. У кандидата цвет берётся по выгоде в
  месяц (`net_monthly`). Булевы значения в таблицах — зелёная галочка или красный
  крестик вместо «да/нет».
- Дашборд: карточки «Количество сообщений», «Доставлено», «Процент доставленных»,
  «Шаблонов», «Кандидатов», «Выгода шаблонов» и блок «Основное» со строками
  «Всего / Обычные / Шаблонированные» и колонками «Сообщений», «Сегментов»,
  «Счёт», «Средняя стоимость сегмента», «Процент» (шрифт таблицы — в полтора раза
  крупнее). Ниже — таблица по операторам получателя: сообщения, сегменты, счёт,
  средняя стоимость сегмента и доля от всех сообщений. Доли и средняя стоимость
  считаются по SMS-сегментам. Справа от таблиц — круговые диаграммы долей
  сегментов и расходов, а также долей сегментов и счёта по операторам (топ-5,
  остальные — «Другие»).
- Дашборд, блок «Дополнительно»: уникальные абоненты (номера получателей) и
  среднее число сегментов и сообщений на абонента; гистограммы абонентов и
  сообщений по числу SMS-сегментов (1–9 отдельно, дальше — диапазоны 10–19,
  20–49, 50–99, 100+) с количеством и долей; круговая диаграмма абонентов по
  операторам. Оператор абонента — тот, по которому у него больше всего сообщений.
- Вкладка «Шаблоны»: полный текст шаблона в колонке «Шаблон» и рядом —
  компактный список операторов регистрации. Щелчок по тексту открывает окно с
  полным текстом и копированием в буфер обмена. Денежные колонки — месячная
  модель для сопоставимости с кандидатами: «Стоимость/мес», «Без шаблона/мес»,
  «Шаблон/мес», «Выгода/мес»; подсказка показывает фактические суммы периода.
  Та же экстраполяция на 30 дней, что у кандидатов.
- Шаблоны по правилам МТС-Маркетолог (раздел 9.1 `AGENTS.md`): переменные
  `%w`, `%w{1,n}`, `%d`, `%d+`; проверка синтаксиса при импорте; подпадание под
  шаблон по отправителю и тексту; процент срабатывания (доля подпавших
  сообщений, оплаченных как шаблонированные) и его разбивка по операторам
  получателя с долей подпавших сегментов.
- Импорт «Список шаблонов.xlsx»: колонки `ID шаблона`, `Текст шаблона`,
  `Текст (пример) шаблона`, `Имя отправителя`, `Статус`, `Операторы`; записи
  одного шаблона у разных операторов объединяются по отправителю и точному
  тексту (регистр, пунктуация и пробелы значимы), плата за шаблон взимается
  один раз; импорт заменяет набор шаблонов и сбрасывает кэш анализа.
- Поиск кандидатов (MTS-CSG): детерминированная сигнатурная группировка без
  нечёткой близости — нормализация, канонические сигнатуры, точные группы по
  `(отправитель, сигнатура)`, эмиссия `%d`/`%d{1,n}`/`%d+`/`%w`, слияние
  литеральных участков в `%w{1,n}` только с подтверждением человеком, линтер,
  проверка полным совпадением и защита от чужих совпадений. Отбор групп по
  числу сообщений и SMS-сегментов. Для неполного периода экономическая выгода
  моделируется до целого месяца (30 дней).
- Импорт Excel-статистики МТС: потоковое чтение через `polars`, схлопывание
  биллинговых строк по `ID сообщения` (стоимость и сегменты суммируются),
  отчёт о качестве, идемпотентность по SHA-256, атомарная запись в SQLite (WAL).
- Экспорт Excel-отчёта: листы «Сводка», «Шаблоны», «Операторы», «Кандидаты»,
  «Предупреждения» с методикой расчёта и допущениями.

Импорт запускается и через слой приложения:

```python
from pathlib import Path

from mts_templates.application.dto import ImportStatisticsRequest
from mts_templates.composition import build_container

container = build_container("C:/Users/<user>/AppData/Local/MtsTemplates/app.db")
report = container.import_statistics.execute(
    ImportStatisticsRequest(path=Path("doc/statistics/november.xlsx"))
)
print(report.batch.row_count, report.batch.message_count, report.batch.total_cost)
```
