# Темы оформления

Система тем — часть слоя `presentation`. Бизнес-логика от темы не зависит:
тема задаёт только цвета, шрифты, радиусы и отступы.

## 1. Где что лежит

| Файл | Ответственность |
|---|---|
| `src/mts_templates/application/settings.py` | Идентификаторы тем (`THEME_*`, `THEME_IDS`), сохранение выбора в `settings.toml` |
| `src/mts_templates/presentation/desktop/theme_catalog.py` | Контракт `ThemePalette` / `Theme`, все палитры, генерация QSS (без Qt) |
| `src/mts_templates/presentation/desktop/theme.py` | Применение темы к `QApplication`, доступ к активной палитре |
| `src/mts_templates/presentation/desktop/widgets/theme_card.py` | Превью темы в сетке «Настройки → Внешний вид» |
| `src/mts_templates/presentation/desktop/widgets/settings_page.py` | Сетка карточек (4 колонки), сохранение выбора |
| `src/mts_templates/presentation/desktop/benefit_style.py` | Фоны подсветки строк, выведенные из палитры темы |
| `src/mts_templates/presentation/desktop/contrast.py` | Расчёт контраста WCAG и выбор читаемого текста |
| `src/mts_templates/presentation/desktop/models/table_model.py` | `BackgroundRole` / `ForegroundRole` таблиц с учётом темы |

Тема применяется без перезапуска: `MainWindow.apply_theme` вызывает
`apply_theme(app, theme_id)` и затем `refresh_theme()` у страниц «Шаблоны» и
«Кандидаты», чтобы пересчитать цвета строк. Выбор сохраняется сразу при клике
по карточке, до перезапуска приложение читает `theme` из `settings.toml` и
применяет тему до показа окна — вспышки системной темы нет.

## 2. Контракт темы

`ThemePalette` — цветовые токены, `Theme` — оформление и типографика.
Соответствие названиям из ТЗ:

| ТЗ | В коде |
|---|---|
| `bg` | `palette.window` |
| `surface` | `palette.surface` |
| `surfaceElevated` | `palette.surface_alt` |
| `textPrimary` | `palette.text` |
| `textSecondary` | `palette.text_muted` |
| `border` | `palette.border` |
| `accent` / `accentHover` / `accentPressed` | `palette.accent` / `accent_hover` / `accent_pressed` |
| `focusRing` | `palette.focus_ring` |
| `danger` / `success` / `warning` | `palette.negative` / `palette.positive` / `palette.warning` |
| `shadow` | `palette.shadow` |
| `radius` | `Theme.radius` |
| `fontHeading` / `fontBody` / `fontMono` | `Theme.font_heading` / `font_family` / `font_mono` |
| `spacingScale` | `Theme.spacing_scale` |
| `effect*` | `Theme.hard_shadow`, превью в `theme_card.py`, правила QSS |

Дополнительно: `palette.header` / `header_text` (шапки таблиц), `selection` /
`selection_text` (выделение), `accent_text` (текст на акцентной кнопке),
`accent_secondary` (второй акцент, декор превью), `Theme.border_width`,
`Theme.bold_text`.

Правила:

- Цвета не хардкодятся в виджетах. Если компоненту нужен цвет темы, он берёт
  его из `active_palette()`.
- Семантические цвета (прибыль/убыток) задаются токенами `positive` /
  `negative`, а не фиксированными константами.
- Все пары «текст/фон» проходят WCAG AA (≥ 4.5), обводка фокуса — ≥ 3.0.

## 4. Подсветка строк таблиц

Строка таблицы шаблонов/кандидатов красится по экономической выгоде пятью
уровнями и одним уровнем убытка. Фоны не фиксированы: `row_palette()` смешивает
`positive` / `negative` с `surface` темы. На светлой поверхности получаются
пастельные заливки, на тёмной — глубокие оттенки. `RowsTableModel` для каждой
ячейки возвращает `BackgroundRole` и читаемый `ForegroundRole`
(`readable_text_color`), поэтому текст не совпадает с фоном ни в одной теме.
Галочка/крестик булевых колонок берут `positive`/`negative` темы, а при
недостаточном контрасте — читаемый текст.

## 5. Как добавить 14-ю тему

1. В `application/settings.py` добавить `THEME_MY_THEME = "my_theme"` и внести
   идентификатор в `THEME_IDS`.
2. В `theme_catalog.py` добавить `Theme(...)` в `THEMES`: палитра со всеми
   токенами, шрифты, `radius`, при необходимости `spacing_scale`,
   `hard_shadow`, `bold_text`. Каталог сам проверит совпадение с `THEME_IDS`.
3. В `widgets/theme_card.py` добавить ветку превью в `_draw_preview` /
   `_draw_details` (атмосфера и мелкие детали). Если ветки нет, карточка
   нарисует базовое превью из палитры.
4. Проверить контраст: `uv run pytest tests/test_theme.py` — тест требует ≥ 4.5
   для текста и ≥ 3.0 для `focus_ring`.
5. Добавить проверку цветов строк: `tests/test_benefit_style.py` прогоняет
   `row_palette` для светлой и тёмной поверхности.
6. Запустить приложение и пройти чек-лист раздела 6.

## 6. Чек-лист ручной проверки

- «Настройки → Внешний вид»: карточка видна, превью отличается от соседних,
  выбор отмечается рамкой и галочкой.
- Переключение темы не требует перезапуска; после перезапуска выбранная тема
  восстанавливается без вспышки системной.
- Импорт, дашборд, шаблоны, кандидаты, экспорт, настройки: текст читается,
  шапки таблиц контрастны, выделенная строка не сливается с текстом.
- Таблица шаблонов: строки прибыли и убытка различимы, булевы «Активен» /
  «В списке» читаются, подсказки видны.
- Фокус с клавиатуры (Tab) заметен на полях, кнопках и таблицах.
- Предупреждения и ошибки различимы не только цветом (есть текст и иконка).
- Нет внешних шрифтов и сетевых запросов; прокрутка и переключение вкладок
  не подтормаживают.

## 7. Ограничения

- Тяжёлые растровые текстуры не используются: зерно, схемы, блики и паттерны
  рисуются `QPainter` в превью или задаются QSS.
- Новые зависимости для тем не нужны.
- Системная тема — пустой QSS; её цвета берутся из палитры Qt и перечислены в
  `SYSTEM_THEME` для расчёта контраста и подсветки строк.
